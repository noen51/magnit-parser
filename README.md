# Magnit Parser

Парсер каталога и товаров интернет-магазина **Магнит (magnit.ru)** на Python.

Проект автоматически собирает структуру каталога, товары, цены, остатки, характеристики, состав, пищевую ценность, изображения и другую доступную информацию о товарах, после чего формирует удобный Excel-файл и JSON-данные.

## Возможности

Парсер умеет:

- собирать одну выбранную категорию по ссылке Magnit;
- собирать целый раздел вместе со всеми его подкатегориями;
- собирать основной каталог магазина;
- получать дерево категорий и подкатегорий;
- учитывать конкретный магазин через `shopCode`;
- сохранять принадлежность одного товара сразу к нескольким категориям;
- получать подробную информацию со страниц товаров;
- находить HD-изображения товаров;
- скачивать фотографии товаров;
- скачивать изображения категорий;
- добавлять превью товаров непосредственно в Excel;
- сохранять промежуточный прогресс при длительном парсинге;
- продолжать обработку остальных категорий при ошибке отдельной категории;
- выполнять offline-тест без обращения к сайту.

## Какие данные собираются

Для товара парсер может сохранить:

- главную категорию;
- категорию и подкатегории;
- полный путь категории;
- все категории, к которым относится товар;
- ID категории;
- ID товара;
- название;
- цену;
- старую цену;
- размер скидки;
- наличие акции;
- дату окончания акции;
- остаток;
- рейтинг;
- количество оценок;
- количество отзывов;
- признак «только самовывоз»;
- признак `18+`;
- признак весового товара;
- код магазина;
- SEO-код;
- товарные метки;
- состав;
- калорийность;
- белки;
- жиры;
- углеводы;

- ссылку на страницу товара;
- изображение из каталога;
- HD-изображение;
- размер HD-изображения;
- путь к скачанному изображению.

## Режимы работы

После запуска доступно меню:

1. **Parse one category**  
   Парсинг одной категории Magnit по её URL.

2. **Parse one main section with subcategories**  
   Выбор основного раздела и сбор всех его конечных подкатегорий.

3. **Parse full core catalog**  
   Сбор основного каталога магазина. Может занимать продолжительное время.

4. **Offline Excel/category test**  
   Проверка обработки данных и генерации Excel на тестовых JSON-файлах без подключения к Magnit.

## Результат

Каждый запуск создаёт отдельную папку внутри:

`results/`

Основной файл:

`products.xlsx`

Также сохраняются:

- `products.json` — товары;
- `categories.json` — дерево категорий;
- `summary.json` — информация о запуске;
- `errors.json` — ошибки обработки;
- `progress.json` — текущий прогресс длительного парсинга.

При включённой загрузке изображений также создаются папки с фотографиями товаров и категорий.

## Excel

`products.xlsx` содержит несколько листов:

- **Все товары** — общая таблица товаров;
- отдельные листы по основным категориям;
- **Товар-Категория** — связи товаров с категориями;
- **Статистика** — количество уникальных товаров по категориям;
- **Категории** — структура каталога;
- **Сводка** — техническая информация о запуске.

При включённой загрузке фотографий превью товаров добавляются прямо в таблицу Excel, а оригинальные изображения сохраняются отдельно.

## Требования

- Windows
- Python 3.13 или совместимая версия
- Yandex Browser, Microsoft Edge или Google Chrome
- интернет-соединение

Python-зависимости:

- Playwright
- openpyxl

## Установка

Рекомендуется распаковать проект в папку с английским названием, например:

`C:\MAGNIT_PARSER`

После этого запустить:

`INSTALL.cmd`

Установщик:

1. создаст виртуальное окружение `.venv`;
2. установит необходимые Python-пакеты;
3. проверит импорт зависимостей.

После успешной установки можно выполнить:

`TEST.cmd`

Для запуска парсера:

`RUN.cmd`

## Браузер

Парсер работает через Playwright и использует установленный браузер.

Приоритет поиска браузера:

1. Yandex Browser
2. Microsoft Edge
3. Google Chrome

Для работы используется отдельный persistent browser profile, благодаря чему выбранный магазин и другое состояние браузерной сессии могут сохраняться между запусками.

### Важно

Папки браузерного профиля не должны публиковаться или передаваться другим пользователям:

- `browser_profile_yandex/`
- `browser_profiles/`

Они исключены из Git через `.gitignore`.

## Тестирование

Offline-тест запускается через:

`TEST.cmd`

или:

```bash
python app.py --test
```
Для тестирования используются:

- `sample_goods.json`
- `sample_categories.json`

Это позволяет проверить обработку данных и создание Excel без запуска live-парсинга сайта.
